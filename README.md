🐘 Ganpati Bappa – Python Drawing Animation

A creative Python-based project that generates a **beautiful animated Ganpati Bappa line-art drawing** using image processing and graphical rendering. The project traces the Ganpati outline and progressively draws it on a black background with a glowing orange/golden effect.

### ✨ Features

* 🐘 Animated Ganpati Bappa line-art drawing
* 🎨 Orange/golden drawing effect on a dark background
* 🖼️ Image processing using OpenCV
* 🖥️ Real-time rendering using Pygame
* ✍️ Automatic contour/path detection
* ⚡ Smooth progressive drawing animation

### 🛠️ Technologies Used

* Python
* OpenCV
* Pygame
* Image Processing
* Contour Detection
